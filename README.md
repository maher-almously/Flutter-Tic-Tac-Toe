# Tic Tac Toe

Tic Tac Toe is a **two-player game** built with **Flutter** and **Dart**.
Players can **set their names** and choose their symbol (X or O) before starting the game.

## Features
- Two-player gameplay with customizable names and symbols (X or O)  
- **Game reset/restart** functionality to play again with the same or new players  
- **Exit button** to close the app  
- Mobile-optimized, responsive interface for smooth gameplay  
- Turn tracking to indicate which player’s turn it is
